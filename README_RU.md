## Торговый журнал

**[Открыть Дашборд в сети](https://andrey-trading-journal.streamlit.app/)** | **[Скачать полный аналитический PDF-отчет](https://disk.yandex.ru/i/oLaoQ6SHewAy4w)**

Интерактивный дашборд для глубокого анализа торговой статистики и риск-менеджмента. Проект создан для автоматизации трекинга сделок, выявления прибыльных/убыточных паттернов и визуализации общих результатов торговли.

## Стек технологий
- **Python** - Основная логика
- **Pandas** - ETL-процессы, вычисления
- **Plotly** - Интерактивная визуализация данных
- **Streamlit** - Веб-интерфейс
- **PostgreSQL + SQLAlchemy** - Хранение данных и подключение к БД

## Ключевой функционал
- **Полный ETL-пайплайн** - Скрипты очищают сырые данные, восстанавливают пропущенные значения (где это возможно) и загружают их в реляционную базу данных PostgreSQL.
- **Динамическая фильтрация** - Фильтрация по классу активов (Крипта/RWA), размеру депозита, годам и месяцам.
- **Анализ эквити** - Построение кривой эквити с динамически рассчитываемой скользящей средней (MA) для оценки трендов доходности.
- **Сегментация статистики** - Детальная разбивка результатов по 7 параметрам: день недели, торговая сессия, паттерн, сетап, направление позиции (Long/Short), торговая пара и контртрендовые сделки.
- **Экстремумы эффективности** - Алгоритм выявления лучших и худших результатов на основе заданных метрик. Включает динамическую защиту от выбросов (требует минимального количества сделок для расчета).
- **Анализ ошибок** - Трекинг торговых ошибок, их распределение по торговым сессиям и расчет суммарных убытков от них.
- **Продвинутая статистика и риск-менеджмент** - Встроенная симуляция Монте-Карло для оценки вероятности прохождения проп-челленджей, воронка конверсии аккаунтов, расчет оптимального размера позиции по критерию Келли и тепловая карта профита по любым доступным критериям.
